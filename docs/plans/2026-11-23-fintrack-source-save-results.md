# ENT-01d — بستن فرم مدیریت منبع پس از ذخیره

روی API 35 مبنا، منبع QA ENT01d baseline از فرم واقعی ساخته و در SQLite ذخیره شد؛ پس از پایان انیمیشن ذخیره، UIA فقط ۹ گرهٔ پوسته و صفر متن قابل استفاده داشت و فهرست در دسترس نبود. شاهد محلی: ent01d-baseline-after-save.png/xml و ent01d-baseline-result.json در .artifacts/fintrack-2026-11-22. مقدار uiNodes با تعداد متن‌های قابل تعامل یکی نیست؛ معیار نتیجهٔ نهایی textNodes=0 است.

دلیل در سورس روشن بود: SourcesScreen پس از SavedSource، SourceIntent.SelectedSource را می‌فرستاد؛ این intent روی ارسال Channel به مصرف‌کنندهٔ picker منتظر می‌ماند. صفحهٔ مدیریت آن effect را جمع نمی‌کرد، پس isAddShow پاک نمی‌شد و شیتِ پنهان هنوز در ترکیب باقی می‌ماند.

callback ذخیرهٔ مدیریت اکنون ResetFlags را ارسال می‌کند: فرم و انتخاب مدیریتی بسته می‌شوند و همان state فهرست، دادهٔ مشاهده‌شده و query باقی می‌مانند. SourceBottomSheets مربوط به picker همچنان مصرف‌کنندهٔ AddedSource و همان پروتکل انتخاب را دارد. فایل مالک فرم و قرارداد مشترک انتخاب تغییر نکردند.
