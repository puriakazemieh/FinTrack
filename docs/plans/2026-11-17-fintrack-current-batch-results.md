## نسخه و آزمون

DirectDebug، مبنای سورس `38742f3c` همراه اصلاحات همین نوبت؛ SHA-256 نسخهٔ تجمیعی `bc6462af9e38ecd1d24ae142691628889aff9529cb8000bbdc04f4a7f2eebedb`. build و تست ماژول SMS موفق؛ مجموعهٔ رگرسیون JVM برابر ۱۲۱ تست با صفر failure/error بود. روی API 31، ۹ آزمون Android هویت/اکشن/ثبت مالی با همین APK پاس شدند و پایگاه داده عیناً بازگردانده شد.

هدر روی `Pixel_9_Pro_XL`، `emulator-5554`، API 35، فارسی و GLASS_DARK نصب و اجرا شد. محدودهٔ واقعی متن حذف `[108,230][280,296]`، عنوان `[593,195][1140,279]` و بستن `[1200,227][1272,299]` بود: ترتیب فیزیکی حذف، عنوان، بستن از چپ به راست صحیح است. روی عرض ۳۶۰dp و قلم ۱۵۰٪ نیز عنوان کامل و بدون هم‌پوشانی بود؛ محدوده‌های حذف، عنوان، بستن به‌ترتیب `[108,388][380,491]`، `[476,192][876,531]` و `[936,404][1008,476]` ثبت شدند. اندازه، تراکم و قلم به حالت مبنا برگردانده شدند.

شواهد هدر و تأیید حذف در `.artifacts/fintrack-2026-11-17/header/` و لاگ‌های `header-ui.log` و `header-themes.log` هستند. تأییدها با انصراف بسته شدند؛ این بازآزمایی هیچ پیامکی را حذف نکرد.

هر چهار تم شیشه‌ای تیره/روشن و سادهٔ تیره/روشن پاس شدند. انگلیسی نیز با متن واقعی `Remove all` و عنوان `Detected text messages` همان ترتیب را داشت؛ `header-english.log`. تصاویر فارسی، باریک و انگلیسی بررسی شدند. در تلاش اول انتخاب زبان، برچسب فرضی «انگلیسی» پیدا نشد؛ انتخاب‌گر متن واقعی `English` دارد و پذیرش از اجرای اصلاح‌شده ثبت شد. زبان فارسی و تم شیشه‌ای تیره برگردانده شدند؛ `header/data-proof.json` برابری دقیق دیتابیس با قبل از آزمون UI را تأیید می‌کند.

APK قدیمی `69c0f531` در worktree مبنا و `upgrade-before.db` همراه لاگ/فیلم آزمون ارتقا محفوظ‌اند. برای بازتولید آزمون ارتقای جدید باید fixture تازه از همان APK قدیمی ساخته شود؛ دو snapshot حذف‌شده دیگر موجود نیستند. گزارش تاریخی BASE-02، وضعیت زمان اجرای خودش را شرح می‌دهد.

## تصویرهای اندروید پایین‌تر

API 31 و 35 آماده و استفاده شده‌اند. طبق ماتریس پلن هنوز system image مربوط به **API 24 یا 25، API 26 و API 33** لازم است. نصب Android SDK Platform به‌تنهایی AVD آن API را فراهم نمی‌کند؛ برای این تست‌ها تصویر امولاتور x86_64 لازم است. API 34 یا بالاتر فعلاً با API 35 پوشش اولیه دارد. دانلود خودکار بعضی تصویرها به علت دریافت ناقص manifest/خطای bootstrap ابزار متوقف شده و جزئیات تلاش در گزارش API 31 آمده است؛ دادهٔ ناقص نصب نشده است.

## توقف درخواستی
